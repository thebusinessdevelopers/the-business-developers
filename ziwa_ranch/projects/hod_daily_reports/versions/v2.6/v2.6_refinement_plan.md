## Technical reference (unchanged from original design)

### Daily brief

Problem: card returns `null` when `report_count === 0`; generic skeleton; errors swallowed. API already returns counts and degraded payloads — client-only fixes.

### Exports

Problem: `formatFieldValue` uses `JSON.stringify` for plain objects; `room_grid` is `Record<slug, RoomData>`.

### Offline queue

Problem: `ConnectivityBanner` uses `useSubmissionQueue()` without success callback; queue success does not pass `reportId` to `NewReportForm`.

### Thread

Problem: `ThreadView` relies on async `sending` state only; add ref guard for synchronous double-fire.
